# uft-module-6
> LogicRoom's _Ultra Fast Testing_, module 6

LogicRooms's epic and very hardcare frontend courses Infinite Architecture and Ultra Fast Testing has the best content available, but Pete Heard wanted to do other things after a decade, so the course platform ended its services in November of 2025.

This was module 6 of Ultra Fast Testing, which is about testing approaches that create high-value frontend tests that are not coupled to the framework du-jour and that scale both vertically and horizontally. 

[Deployed at Github Pages](https://fatso83.github.io/uft-module-6/)
with a [self-hosted backend](https://github.com/fatso83/cf-workers-books-api) 
running on Cloudfront Workers and Durable Objects.
